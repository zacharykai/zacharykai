# Zachary Kai

Hi! I'm [Zachary Kai](https://zacharykai.net), a space fantasy writer. Also an offbeat queer, twenty-something, curiosity enthusiast, and traveler.

An avowed generalist, and learning to be proud of it.

## What I'm Up To

- Writing space fantasy with Lunaseeker Press.
- Tending my corner of the web: hand-written HTML and CSS, no JavaScript, built by little PHP scripts that run on my own computer.
- Reading, and then rambling about it on my book blog.
